## Installation

1. Clone repo
2. run `npm install`

## Usage

1. run `node server.js`
2. Navigate to `localhost:5000`

## Credit

Modified from Scotch.io's auth tutorial

Tech used:

✅ HTML, CSS, EJS – Structuring and styling dynamic pages.
✅ JavaScript & Express.js – Powering interactivity and backend logic.
✅ MongoDB – Storing song lyrics, artwork, and user data.
✅ Cloudinary – Managing and storing media files like images or audio.
✅ Passport – Handling authentication for artists logging in.


Plumes is an artistic hub where creators can store and organize their ideas—whether it's song lyrics, melody recordings, or artwork. It eliminates the frustration of searching for scattered creative work across multiple platforms like your gallery or notes app, ensuring easy access so your best ideas are never forgotten!

Lessons Learned:
This is my first big full-stack application, and it's still giving me that wow I can do this! moment.
